About the project and model

Problem and objectives

Institutions often notice struggling students only after results. This system estimates performance from signals available before the final exam so that advisors can offer help early.

  • Predict final exam marks and percentage
  • Classify Excellent / Good / Average / At Risk
  • Explain each prediction
  • Recommend personalised actions
Methodology

Clean data, engineer features (assignment completion rate, academic consistency, engagement index), split 80/20, compare models with 5-fold cross-validation, tune with grid search, evaluate on held-out data. Preprocessing and model are saved as one scikit-learn Pipeline to avoid leakage and train/serve mismatch.

Limitations and ethics
  • The model is trained on synthetic data, so metrics show pipeline behaviour, not real-world accuracy.
  • Predictions are estimates and can be wrong; use them to start a conversation, never to decide a student's outcome alone.
  • Real deployments need bias and fairness audits across groups, privacy protection (anonymised IDs, consent, access control) and human review.
  • Gender is a collected feature here for demonstration; consider removing sensitive attributes in production.
